01 / El problema

Lanzar más productos sin romper la marca.

En un portafolio masivo, cada ficha, guion y packshot improvisado diluye voz, paleta y promesa. El costo no es creativo: es consistencia.

Atelier · Reto técnico Alicorp IAGen

02 / La solución

Un taller con una sola fuente de verdad.

Atelier convierte un brief en DNA de marca, lo indexa, genera copy contra ese manual y deja que dos aprobadores cierren el circuito: texto en Mesa, imagen en Visión.

03 / Arquitectura

Front y API modulares, por separado.

Backend

FastAPI en capas: domain → application → infrastructure → api. Los ports (LLM, visión, repos) se inyectan; Groq o template no tocan el dominio.

Frontend

Next.js por features (DNA, Prensa, Mesa, Visión). Tipos en domain, providers en application, fetch solo en infrastructure.

Datos + RAG

Supabase Postgres. Chunks del manual con pgvector para recuperar reglas, no para repetir el brief.

Modelos

Groq escribe el DNA y el copy. Gemini 3.6 Flash audita la pieza gráfica contra el mismo manual.

04 / Flujo

Cuatro mesas. Un expediente.

  • Creador: DNA y Prensa (ficha, guion, prompt de imagen).
  • Aprobador A: cola de Mesa, veredicto.
  • Aprobador B: auditoría multimodal.
  • Langfuse: qué se recuperó, qué prompt salió, cuánto tardó la visión.
05 / Valor al negocio

Menos retrabajo. Más control.

El manual deja de ser un PDF que nadie abre. Cada pieza nace citada. La aprobación deja rastro. Marketing escala SKUs sin multiplicar deriva de marca.
